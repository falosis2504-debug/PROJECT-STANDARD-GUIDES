### 2. 주석 / 문서화
- 파일·클래스·public 메서드 주석 필수 범위
- 형식(Javadoc/JSDoc/Docstring), 작성 언어
- TODO/FIXME 표기: `TODO(담당자, 일자): 내용`
- 주석 처리된 코드 커밋 금지

### 3. 예외 처리
- 예외 계층 구조(업무 예외 / 시스템 예외)
- 빈 catch 금지, 예외 삼키기 금지
- 사용자 메시지 vs 로그 메시지 분리

### 4. 로깅
| 레벨 | 사용 기준 |
|---|---|
| ERROR | 처리 불가, 즉시 조치 필요 |
| WARN | 복구 가능한 이상 |
| INFO | 주요 업무 이벤트 |
| DEBUG | 개발 진단 (운영 비활성) |
- 로그 포맷, 추적ID(Trace ID), 개인정보·비밀번호 로깅 금지

### 5. 보안 코딩
- 입력값 검증, SQL Injection(바인딩 변수 필수), XSS, CSRF
- 시크릿(키/비밀번호) 코드·저장소 커밋 금지, 설정/Vault 사용
- 개인정보 암호화·마스킹 기준
- (참고) 행정안전부 소프트웨어 개발보안 가이드 / OWASP Top 10
