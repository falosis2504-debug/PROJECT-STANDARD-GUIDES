# 00. 문서 거버넌스

- 상태: 초안 | 버전: 0.1 | 작성자: | 최종수정:

## 목표
표준 문서를 누가, 어떻게 작성·승인·변경하는지 정한다.

## 작성 항목
### 1. 문서 관리 규칙
- 파일 위치/이름: `docs/NN-영문-kebab-case.md` (NN = 단계 번호)
- 상태값: 초안 → 검토 → 확정
- 버전: `Major.Minor` (확정 후 규칙 변경=Major, 보완=Minor)

### 2. 역할과 승인 [결정 필요]
| 역할 | 담당 | 책임 |
|---|---|---|
| 표준 관리자(PA/아키텍트) | | 표준 작성·승인 |
| 개발 리더 | | 적용 점검 |
| 개발자 | | 준수 |

### 3. 표준 변경 절차 [결정 필요]
1. 변경 요청(이슈/PR) → 2. 영향도 검토 → 3. 승인 → 4. 변경이력 기록 → 5. 공지

### 4. 예외 처리 원칙
표준을 따를 수 없는 경우 사유·범위·기한을 기록하고 승인받는다.

### 5. 용어 정의
| 용어 | 정의 |
|---|---|
| MUST / 필수 | 반드시 준수 |
| SHOULD / 권장 | 특별한 사유가 없으면 준수 |
| MAY / 선택 | 상황에 따라 선택 |
