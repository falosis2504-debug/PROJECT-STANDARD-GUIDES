# 프로젝트 표준 가이드 (Project Standards)

모든 프로젝트 시작 시 기틀이 되는 명명규칙·개발 가이드 문서 세트.
SI 개발사업의 통상적인 표준화 산출물 체계(공통기준 → 명명규칙 → 코딩/설계 표준 → 형상/배포 → 품질)를 따른다.

## 사용 방법
1. 아래 **단계별 로드맵**의 순서대로 문서를 하나씩 채운다. (앞 단계가 뒤 단계의 전제)
2. 각 문서 상단의 `상태`를 `초안 → 검토 → 확정`으로 갱신한다.
3. 문서마다 `[결정 필요]` 표시 항목은 결정 후 표를 채우고 표시를 지운다.
4. 확정된 문서는 변경 시 `변경이력`에 기록한다.

## 권장 진행 순서와 이유
- **2단계(명명규칙)** 가 가장 먼저 실질 가치를 낸다. 0·1단계는 짧게 끝내고 바로 2단계로 가도 된다.
- 3~4단계는 사용하는 언어/프레임워크가 정해져야 구체화된다. → 1단계에서 기술스택을 먼저 확정.
- 7단계는 마지막에, 앞 문서를 재사용 가능한 템플릿으로 정리하며 작성한다.
