# 07. 프로젝트 킥오프 체크리스트

- 상태: 초안 | 버전: 0.1

## 목표
신규 프로젝트에 이 표준 문서 세트를 적용하는 절차를 정리한다. (마지막 단계에서 작성)

## 적용 절차
1. 이 `docs/` 를 신규 저장소로 복사
2. 프로젝트별 값(기술스택, 업무코드, 환경)을 `[결정 필요]` 항목에 채움
3. 린터/포매터/CI 설정 파일 생성 (`.editorconfig`, 린터 설정, 파이프라인)
4. 팀 공유 및 교육, 확정 후 버전 태깅
